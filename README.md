# Proyecto 1: HTML y CSS

Portfolio ficticio de Gazrik Tuercafloja, creado como proyecto del máster utilizando HTML5 y CSS3.

## Contenido

- index.html: estructura y contenido de la página.
- styles.css: estilos y adaptación a distintos tamaños de pantalla.
- media/: imágenes utilizadas en el portfolio.

## Características

- Estructura HTML semántica.
- Navegación entre secciones.
- Galería de cuatro proyectos con CSS Grid.
- Uso de Flexbox.
- Diseño adaptable a móvil, tableta y escritorio.
- Formulario de contacto de demostración, sin envío de datos.
